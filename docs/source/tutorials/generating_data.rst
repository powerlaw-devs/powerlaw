Generating data
===============

Creating simulated data drawn from a theoretical distribution is frequently
useful for a variety of tasks, including further modeling or simulations.
Individual ``Distribution`` objects can generate random samples with the
:meth:`Distribution.generate_random`.

Let's first create a distribution by manually specifying parameter values:

.. plot::
    :caption: A power law with exponent :math:`\alpha = 2`.
    :filename-prefix: powerlaw_slope_2
    :context: reset

    import powerlaw
    import matplotlib.pyplot as plt

    # Any of these are fine to create a power law with a specific
    # alpha value.
    pl = powerlaw.Power_Law(xmin=1, parameters={'alpha': 2.0})
    pl = powerlaw.Power_Law(xmin=1, parameters=[2.0])
    pl = powerlaw.Power_Law(xmin=1, alpha=2.0)

    pl.plot_pdf(label='PDF')
    pl.plot_ccdf(label='CCDF')
    
    plt.legend()
    plt.show()

Now let's sample from that distribution, and plot the new PDF:

.. plot::
    :caption: A power law with exponent :math:`\alpha = 2` generated by sampling from the manually defined distribution.
    :filename-prefix: powerlaw_slope_2_sampled
    :context: close-figs

    # The first argument is equivalent to `size` from all
    # numpy.random functions.
    samples = pl.generate_random((10000,))

    pl.plot_pdf(label='Original PDF')
    powerlaw.plot_pdf(samples, label='Sampled PDF')

    plt.legend()
    plt.show()

The random sampling will follow the properties of the parent distribution,
which means it will respect values of ``xmin`` and ``xmax`` (if provided).
In the above case, we didn't specify an ``xmax`` for our parent distribution,
so the random samples are unbounded on the upper side (though note that
we arbitrarily choose to only plot three decades of the original distribution).
If we generate sufficiently enough samples, we can see that the sampled distribution
extends much farther than the original, though again this is simply because
we chose to only plot three decades of the original one:

.. plot::
    :caption: A power law with exponent :math:`\alpha = 2` generated by sampling a large number of values from the manually defined distribution. Note how the sampled distribution contains rare values that extend beyond the curve of the original distribution.
    :filename-prefix: powerlaw_slope_2_sampled_large_n
    :context: close-figs
    :include-source: False

    # The first argument is equivalent to `size` from all
    # numpy.random functions.
    samples = pl.generate_random((1000000,))

    pl.plot_pdf(label='Original PDF')
    powerlaw.plot_pdf(samples, label='Sampled PDF')

    plt.legend()
    plt.show()

If we instead provide a specific value for ``xmax``, our sampled distribution
will be restricted to the region :math:`[x_{min}, x_{max}]`.

.. plot::
    :caption: A power law with exponent :math:`\alpha = 2` generated by sampling from the manually defined distribution in a bounded domain.
    :filename-prefix: powerlaw_slope_2_sampled_bounded
    :context: reset

    import powerlaw
    import matplotlib.pyplot as plt

    # Any of these are fine to create a power law with a specific
    # alpha value.
    pl = powerlaw.Power_Law(xmin=1, xmax=1e3, alpha=2.0)

    pl.plot_pdf(label='PDF')
    
    samples = pl.generate_random((10000,))

    powerlaw.plot_pdf(samples, label='Sampled PDF')

    plt.legend()
    plt.show()

This random generation is exactly the same for a distribution fit to some
data:

.. plot::
    :caption: PDF of original ``flares`` data and random samples drawn from the power law fit.
    :filename-prefix: flares_random_samples
    :context: reset

    import powerlaw
    import matplotlib.pyplot as plt

    data = powerlaw.load_test_dataset('flares')

    # Note: no xmax, so the samples will be unbounded
    fit = powerlaw.Fit(data)
    samples = fit.power_law.generate_random((10000,))

    fit.plot_pdf(label='Original PDF')
    powerlaw.plot_pdf(samples, label='Sampled PDF')

    plt.title('flares')
    plt.legend()
    plt.show()

This random sampling function is used, for example, to validate the
fitting algorithm against simulated data.

.. plot::
    :caption: Results of fitting randomly generated data according to continuous power law distribution.
    :filename-prefix: random_gen_validation

    import powerlaw
    import numpy as np
    import matplotlib.pyplot as plt

    np.random.seed(0)

    alpha_arr = np.linspace(0.5, 2.5, 100)
    num_samples = 10 # per alpha value
    N = 3000

    fit_alpha_arr = np.zeros((len(alpha_arr), num_samples))

    for i in range(len(alpha_arr)):
        for j in range(num_samples):
            theoretical_dist = powerlaw.Power_Law(xmin=1, xmax=1e6, alpha=alpha_arr[i])
            data = theoretical_dist.generate_random(N)

            fit = powerlaw.Fit(data, xmin=1, xmax=np.max(data))

            fit_alpha_arr[i,j] = fit.power_law.alpha

    for i in range(len(alpha_arr)):
        plt.scatter(np.repeat(alpha_arr[i], num_samples), fit_alpha_arr[i], alpha=0.1, c='tab:blue')

    plt.plot(alpha_arr, alpha_arr, '--', c='tab:orange', label='$y=x$')

    plt.xlabel('True alpha')
    plt.ylabel('Fit alpha')

    plt.title('Continuous power law validation')
    plt.legend()
    plt.show()
